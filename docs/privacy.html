ホームプライバシーポリシー

プライバシーポリシー

最終更新日：2026年11月2日

1. 対象

本ポリシーは、rclone-sync-note（以下「本アプリ」）における、Google アカウントのデータの取り扱いを定めます。本アプリは運営者本人だけが使う個人用の設定です。

2. アクセスするデータ

本アプリは、Google の OAuth 認証を通じて、運営者本人の Google ドライブ上のファイルとフォルダ（名前、内容、更新日時などの情報）にアクセスします。

3. 利用目的

アクセスしたデータは、運営者のパソコンと Google ドライブとの間でファイルを同期する目的にだけ使います。

4. 保存と送信

  • 同期したファイルと認証情報（トークン）は、運営者のパソコン上にだけ保存します。
  • データを、運営者以外の第三者のサーバーへ送ることはありません。

5. 第三者への提供

データを第三者に提供、販売、共有することはありません。また、広告、分析、機械学習モデルの学習には使いません。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリが Google API から受け取った情報の利用と他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

7. データの削除とアクセスの取り消し

運営者のパソコン上の rclone 設定を削除すると、保存された認証情報も消えます。また、Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本アプリのアクセスを取り消せます。

8. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub Issues までお願いします。

9. 変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。

Summary (English)

  • rclone-sync-note is a personal rclone configuration used only by its owner.
  • It accesses the owner's own Google Drive files solely to sync them with the owner's computer.
  • Files and OAuth tokens are stored only on the owner's computer. No data is sent to any third-party server.
  • Data is never sold, shared, or used for advertising, analytics, or training machine-learning models.
  • The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time at myaccount.google.com/permissions.
  • Contact: GitHub Issues.
